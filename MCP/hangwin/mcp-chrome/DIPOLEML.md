# MCP Chrome

**DipoleML integration** for Hangwin. Type: `mcp`. Version: `1.0.0`.

Chrome MCP Server is a Chrome extension-based Model Context Protocol (MCP) server that exposes your Chrome browser functionality to AI assistants like DipoleML, enabling complex browser automation, content analysis, and semantic search.
