# HWPX 빈 입력란과 표 구조 100% 검증 — 4.18.1

기준선은 4.18.0 main751928c다. 기존 참조와 기준선 파서로 원본 2,286문서·9,865표를 다시 실행해 9,849표(99.8378%) 일치를 재현했다. 남은 16개를 원본 4문서·9개 물리 표·181개 직계 셀 주소·스팬·테두리와 대조했다.

이전 감사에서 정답 결함으로만 분류했던 14곳에는 실제 파서 손실도 있었다. 국제출원서 13개 사각 입력란과 인영신고서 1개 3면 입력란은 글이 없지만 실제 선이 그어진 셀이다. 혼합 틀 표에서 보이는 구간을 나눈 뒤, 후행 빈 열 정리가 마지막 앵커를 1→0으로 지웠다. 기존 후행 열 정리를 유지하되 마지막 앵커 삭제를 막고 빈 한 칸을 기존 HTML 직렬화로 내보내 IR뿐 아니라 Markdown에도 입력란을 남긴다. 일반 글 셀의 한 칸·한 열 출력은 유지한다.

채점 기준 변경: 독립 참조 추출기도 같은 입력란의 마지막 앵커를 지워 −1×−1 정답을 만들었다. 또한 실제 수식만 든 열을 글이 비었다는 이유로 지웠다. 원본 수식 존재를 빈 칸 판정에 반영하고 빈 입력란의 유효 격자를 복원한다. 셀 텍스트 비교에서는 수식 제외 정책을 유지하며, 대응·엄격한 치수/주소/스팬 비교·정규화·제외·모수는 변경하지 않는다. 문서별 예외나 파서 결과 복사는 없다.

표 수정 빌드의 수정 참조 채점은 **9,865/9,865 구조 일치·cellF1 100%**다. 같은 2,286개 문서 식별자·9,865표를 네 조합으로 실행했다.

| 독립 참조 | 파서 4.18.0 | 파서 4.18.1 |
|---|---:|---:|
| 기존 참조 | 9,849 (99.8378%) | 9,849 (99.8378%) |
| 수정 참조 | 9,851 (99.8581%) | 9,865 (100%) |

참조 정정만으로 2개 수식 표가 맞고, 같은 수정 참조에서 파서가 실제 복원한 빈 입력란 14개가 추가로 맞는다. 기존에 맞던 9,849표의 exact 회귀는 0이다. 전후 셀 본문 NED 99.9953%·cellExact 99.9982%는 그대로다. 원점수와 보고서 SHA는 [교차 채점 기록](hwpx-empty-fields-2026-10-01/cross-score.json)에 보존하며, 정상 npm 게시의 전체 게이트에서도 같은 9,865/9,865표를 확인했다. 공개 패키지의 원본 입력란 14개·ESM/CJS·CLI와 dist 136파일 일치, GitHub 첨부파일 바이트 일치, GitLab main·태그 동기화는 [배포 기록](release-4.18.1.json)에 보존한다. 원래 잘못된 참조 그대로의 100%라고 표현하지 않는다. 표 구조 완전 일치와 셀 본문 NED·시각 일치는 서로 다른 지표다.

원본 구조를 그대로 추출할 때에는 layoutTables:"keep"와 keepTrailingEmptyCols:true를 함께 쓴다. 인영신고서의 두 입력란 중 끝 열 등 전체 표의 후행 빈 열을 접는 기존 기본 정책은 이번 구간 수정과 별개다. 100%는 기존 보이는 표 정규화 정의 안의 구조 일치이며, 한컴 GUI 픽셀 일치나 모든 원본 편집 격자 재현율이라고 주장하지 않는다.

[원본 파일·셀 근거](hwpx-empty-fields-2026-10-01/original-evidence.json), [16개 사례](hwpx-empty-fields-2026-10-01/cases.jsonl), 기존 [9/30 감사](hwpx-table-original-audit-2026-09-30.json)를 함께 보존한다.

빈 표의 HTML 보존을 전체 패치 테스트에도 적용했다. HWP5에서 기본 출력과 원본 구조 출력이 다르더라도 편집본이 기본 출력과 정확히 같으면 위치 매핑 없이 원본 바이트를 반환한다. 검증 diff도 같은 출력 모드로 잔차 0을 확인하며, 실제 기본 출력의 편집은 기존 원본 구조 모드 요구를 유지한다. 코퍼스 없이 재현되는 검증 켬/끔·실제 편집 거부 테스트와 기존 전수 무수정 패치를 함께 실행한다.

4.18.1 배포를 완료했다. HWP5 짝 비교도 같은 입력란 14개가 양쪽에 복원되어 4,258/4,258표가 일치한다. PDF 전체 채점·표·본문 보고서의 비시간 원시 결과는 이전 버전과 동일하다. 전체 테스트는 2,922개 중 통과 2,917·실패 0·Linux 전용 환경 생략 5개이며 Node 20/22/24 CI가 모두 통과했다. 공개 npm·GitHub 릴리스·GitLab 태그가 같은 소스를 가리킨다.
