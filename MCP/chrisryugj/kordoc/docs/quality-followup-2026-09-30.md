# kordoc 추가 품질 개선 — 2026-09-30

4.17.2를 [npm](https://www.npmjs.com/package/kordoc/v/4.17.2)(latest)과 [GitHub 릴리스](https://github.com/chrisryugj/kordoc/releases/tag/v4.17.2)에 공개했다. HWP5↔HWPX 쌍의 표 대조 100%와 HWPX 자체 표 완전 일치 99.6858%는 별도 지표다. [배포 검증 기록](release-4.17.2.json)에 정상 게시 게이트·패키지 해시·실제 CLI 실행과 사용자 시각 게이트 override를 기록했다.

기준 커밋은 a4158ee이며, GT·평가기·표본·제외 목록·옵션은 유지했다. 세부 근거와 실행 소스 해시는 [JSON 기록](quality-followup-2026-09-30.json)에 있다.

HWPX 2,286문서·9,865표에서 완전 일치 표가 9,829→9,834개가 됐다. 테두리 정의가 있는 파일의 참조 0은 선 없음이며, 정의가 없는 파일은 미상으로 유지한다. HWP5에도 같은 의미를 적용해 실제 4쌍의 표·칸·내용 일치율을 100%로 복구했다.

ODL 원본 200문서를 기본·plain + HTML 두 모드로 실행했다. 398/400개 Markdown은 바이트 동일하고, 163 리플릿의 QR 캡션·표지 순서만 개선했다. plain + HTML 문서 종합은 88.824264→97.136117이다. 모든 개별 지표 회귀·실패·누락은 0건이고 OCR 경고·HTML 표 개수·TEDS는 유지했다.

한국 PDF 글 744문서와 coverage 1,911문서는 직전 개선 결과를 모두 보존했다. 최종 전체 채점도 통과했고, HWP/HWPX 1,120쌍·4,244표의 표·칸·내용·커버 지표는 모두 100%다. 처음의 4,249표와 개수가 다른 것은 같은 입력 8문서의 보이지 않는 유령 격자를 제거한 결과이며 표본·정답 변경이 아니다. 글의 spacing F1 98.804, ODL 구조 점수와 OCR 표 점수 등에는 여전히 99 미만 지표가 있으므로 모든 지표 99 달성으로 보고하지 않는다.

OCR의 공정 CER·문자 F1 등은 직전 개선 결과와 동일하다. strict CER(오류율)은 최초 기준 9.531→9.542%의 기존 소폭 증가를 유지하므로, 최초 대비 모든 OCR 수치가 개선됐다고 주장하지 않는다.

## 구현과 검증

- PDF 그림 clipping은 읽기 순서의 가시 영역에서만 사용한다. OCR crop과 그림 칸 판정은 기존 raw CTM bbox를 유지한다. 전역 clipping 후보 A는 OCR 회귀 4문서 때문에 제외했고, 원인을 분리한 B는 400회 원본 평가에서 회귀 없이 개선됐다. 복합·곡선 clip 경로는 보수적으로 원래 영역을 사용한다.
- 같은 행을 공유하는 3열 표와 조각난 전폭 제목은 독립 패널로 분리하지 않는다. oversized 한 칸 grid의 조기 fallback에도 그림 기하를 전달한다.
- 공문서의 굵은 항목부호 구분자가 본문에 남던 것을 수정했다. 글꼴 폭표는 계산 전에 한 번 선택해 문자마다 조회하지 않으며, 기존 알려진 글꼴의 폭·줄바꿈 결과를 보존한다. 미등록 객체 속성 이름의 글꼴도 정상 fallback한다.
- TDD 및 독립 검토 완료: B 집중 62개, 최종 HWP5 집중 61개, OCR raw bbox 1,000개 비교와 글꼴 width 24,192개·wrap 48,384개 동등성 검사 통과. 전체 게시 게이트의 채점·PDF 표·글·라운드트립·별표·포맷·reflow·redact는 통과했고, 단독 fuzz 23,700건도 모든 사고 지표 0으로 통과했다. 마지막 OCR 검사도 통과했고 53문서의 품질·제외 항목은 B와 동일하다. `npm run prepublishOnly` 전체가 종료 코드 0으로 완료됐다. 생성 전수의 36개 ZIP 엔트리 해시도 동일하다.

생성 역재현 벤치의 대표 5문서 서식 속성 점수는 기존 77.0486~86.4407%를 유지한다. 내용 라운드트립 100%, 생성 시간과 원본 서식 속성 역재현율은 서로 다른 지표다.

## 이슈·PR와 배포

[#111](https://github.com/chrisryugj/kordoc/pull/111)은 새 테스트 8개와 CI를 확인한 뒤 병합했고 [#109](https://github.com/chrisryugj/kordoc/issues/109)는 닫았다. 진행 중 다운로드나 확인할 수 없는 소유권은 보존한다. [#110](https://github.com/chrisryugj/kordoc/pull/110)의 병렬 CLI 기능은 검토 의견을 남겼으며, 이번 최소 패치에 섞지 않았다.

버전·lockfile·플러그인 메타는 4.17.2로 맞췄고 패키지 151개 파일과 CLI 버전을 확인했다. npm 게시 전 전체 자동 게이트를 통과했다. 저장소 지침의 한컴 실렌더 검증은 앱 부재로 실행할 수 없었다(맥미니 연결 이름도 미설정). 시각 게이트는 미실행이다. 이후 사용자의 명시적 배포 진행 지시에 따라 정상 npm 게시 게이트 전부 통과 후 공개 배포를 완료했다.

main 커밋 3ff5280의 Node 20/22/24 CI는 모두 통과했다. 미러 OSV가 기존 MCP 간접 의존성 fast-uri 3.1.7 및 ip-address 10.7.0을 거부해 각각 3.1.8·10.7.2로 호환 갱신했다. 이후 전체 2,772테스트(실패·skip 0), typecheck·build·메타·고지·npm audit(취약점 0), CJS/ESM 생성·파싱 통합 검사를 통과했다. 파서 소스와 ESM index 해시는 고정 C와 동일하다. 추가로 실제 npm publish에서 최종 lockfile로 전체 코퍼스 게이트를 재실행했고 모두 통과했다.

[4.17.2 공개 릴리스](https://github.com/chrisryugj/kordoc/releases/tag/v4.17.2)에 검증한 패키지를 첨부했다. npm registry의 latest는 4.17.2이고 공개 태그는 소스 커밋 89b3e52를 가리킨다.

미러는 demo/package-lock.json도 검사하므로 데모의 fast-uri 3.1.7→3.1.8 항목도 갱신했다. 데모 npm audit도 취약점 0이며, 데모 코드는 변경하지 않았다.
