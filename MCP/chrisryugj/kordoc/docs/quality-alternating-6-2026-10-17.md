## PDF 기호의 독립 근거

두 PDF 라운드는 일반 도형·숫자의 추정 범위를 넓히지 않는다. 기존 U+F000 복원 경로에서 글꼴 이름·upm·advance와 모든 윤곽 좌표·순서·oncurve가 원본 글꼴 문자표와 정확히 일치할 때만 해당 사설 문자를 식별한다. 실행 시 로컬 원본 글꼴 설치는 필요 없으며 PDF에 포함된 글꼴 데이터와 코드에 저장한 지문으로 식별한다. 원본 글꼴 설치는 개발 검증의 근거다. 이후 기존 공용 PUA 정책인 F02EF→가운데점, F02B1~6→①~⑥를 사용한다. 문서 ID·CID·임시 fontChar 번호는 식별 조건에 없다.

학교 안전점검 PDF의 HCRDotum 가운데점은 설치 원본 HANDotum.ttf의 cmap F02EF·advance 970·upm 1000과 정확히 같다. 실제 문서에서 13개를 복원했고 전수 결과에서는 글·표 각각 3개 채점행이 개선됐다.

청년일자리 PDF의 Haansoft Batang 번호는 설치 원본 HBatang.TTF의 cmap F02B1~6·advance 1024·upm 1024와 정확히 같다. PDF 폭은 1000em 정규화값 1000이다. HCRBatang은 다른 글꼴이므로 별칭에 넣지 않는다. 23쪽 전체에서 번호 6종이 각각 5개씩, 총 30개 복원됐다. 최초 조사한 2·9쪽만의 12개보다 넓은 전쪽 결과다. 같은 문서 번호의 별도 5쪽 보도자료는 변경 0이며, 두 파일은 파일명과 SHA256으로 구분했다. 이 라운드의 전수 글 지표는 22개 채점행, 표 내용 지표는 5개 채점행에서 개선됐다.

합성 TTF 테스트는 지문 비교와 거부 조건을 검사한다. 문자 의미의 근거는 독립 원본 글꼴 cmap이다. 같은 모양의 다른 글꼴·다른 폭·다른 upm·한 점 또는 oncurve 변형·유효 유니코드·흐름 개수 불일치·Form 글꼴 복귀를 함께 검증했다. 정확한 지문 방식이라 다른 글꼴 버전이나 미등록 번호는 계속 놓칠 수 있다.

## 검증 출처와 한계

PDF 글 744쌍·표 730결과행·별표 544결과행은 모든 라운드에서 추적 지표 하락 0이며 표 셀 내용 완전 일치율도 별도 확인했다. 외부 ODL 200문서×4모드는 PDF 라운드 2·4에서 재측정해 모든 문서의 점수가 같았다. 병렬 실행 시간은 성능 비교로 사용하지 않는다. 조판과 PDF 사이의 직접 점수 상승은 확인하지 못했다. PDF 기호 복원이 글·표 내용·읽기 순서에 함께 효과를 낸 것은 같은 PDF 트랙 안의 교차 효과다.

전체 테스트 4,215개 중 4,206개 통과·9개 스킵·실패 0, 타입검사·빌드를 통과했다.

벤치마크는 결함을 찾은 기존 코퍼스의 회귀 검사다. 이 코퍼스를 보지 않은 독립 holdout의 일반화 점수로 표현하지 않는다. 저장본 좌표와 원본 PDF·글꼴을 외부 근거로 사용하며 2022 재저장 자료는 별도 모수다. GUI 검사는 필수 게이트에 넣지 않는다.
