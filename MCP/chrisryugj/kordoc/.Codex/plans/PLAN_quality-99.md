## 승인과 가정
- 사용자가 질문 없이 최적안으로 진행하고 커밋까지 요청함. 푸시·배포는 이번 범위에 포함하지 않음.
- 모든 수치 99점은 저장소의 0~1 품질 지표 0.99 이상으로 해석. 속도는 동일 입력·환경의 시간/RSS로 별도 비교.
- 정답·평가기·표본·제외 규칙 변경으로 점수를 높이지 않음. 실제 기능 변경만 평가.
- 기존 작업 공간의 미추적 파일과 코퍼스는 보존. 독립 worktree에서 검증.

## 품질 게이트
각 단계에서 실패 테스트를 먼저 확인하고 최소 수정 후 통과 확인. 수정한 소스는 벤치 전 build, 실행 중 재빌드 금지. 퍼즈/성능 측정은 단독 실행. 이전 측정과 같은 입력·옵션 사용. 회귀 발생 시 해당 변경 수정/제거 후 재검증. 실패가 3회 반복되면 원인 분석 후 접근 변경.
