# Projectmem

**DipoleML integration** for Riponcm. Type: `mcp`. Version: `0.0.0`.

Open-source coding agents memory. Records issues, attempts, fixes and decisions, then warns your agent before it repeats an approach that already failed. Native MCP server for DipoleML, Cursor, Antigravity and Codex. 100% local, no cloud, no telemetry. MIT.
