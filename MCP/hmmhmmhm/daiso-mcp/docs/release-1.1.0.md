# 1.1.0 릴리스 노트

## 추가

- 디트릭스 독립·예술영화관 22곳의 카탈로그, 상영작·상영 가능 날짜, 회차별 잔여 좌석을 MCP와 GET API로 제공합니다. 지역·극장명·브랜드 필터를 함께 적용하고, 부분 실패와 전체 장애를 구분합니다.
- 메가박스 CLI 명령 `megabox-theaters`, `megabox-movies`, `megabox-seats`를 추가했습니다.
- 디트릭스 API 명세, Actions 연결, CLI 사용 가이드와 운영 검사를 추가했습니다.

## 수정

- MCP smoke는 오류 응답을 JSON으로 해석하지 않고 원래 오류를 보존합니다.
- Zyte 계정 정지·키 누락과 GS25 인증 장애는 자동 재시도 대신 운영 설정 확인을 안내합니다.
- CU 웹 매장 검색은 공식 GET 경로를 사용합니다. 같은 검색 필드와 기존 Zyte POST 폴백은 유지합니다.
- 공용 JSON·텍스트 요청의 제한 시간을 응답 본문 읽기까지 적용합니다. 본문 오류에 새 재시도를 추가하지 않습니다.
- 현재 Node 타입과 호환되도록 인터랙티브 CLI의 표준 입출력 참조를 수정했습니다.

## 이전 npm 배포 이후 누적 반영

7월 14일의 1.0.10 이후 main에 반영된 Home Assistant 스키마 호환, MCP 오류 응답 계약, 한국 날짜 기준 영화 검색, GS25 공개 매장 API, 롯데시네마 잔여 좌석 계산, 운영 호출 제한 통계와 의존성 보안 수정을 포함합니다.

CLI는 원격 API를 호출하므로 서버 측 수정 중 일부는 기존 CLI에서도 적용됐습니다. 이번 릴리스는 패키지의 코드와 명령을 최신 main에 맞춥니다.

## 의존성

MCP SDK 1.30.0, Wrangler 4.131.2, Workers 타입 5.20260914.1, Biome 2.5.13, Node 타입 26.5.1, Playwright 1.63.0, proj4 2.22.0, globals 17.12.0으로 호환 가능한 갱신을 반영했습니다. Node 런타임 최소 버전은 22입니다.

## 운영 제약

릴리스 자체가 외부 계정이나 인증키를 복구하지는 않습니다. Zyte 정지 상태에서 이를 필요로 하는 서비스는 계속 조회 불가일 수 있으며, GS25 재고에는 유효한 GS25_API_KEY가 필요합니다. 배포 후 검사에서 CU 매장 검색은 HTTP 400, CU 앱 매장·재고는 JSON 대신 HTML 응답을 확인했습니다. 디트릭스 상영 정보는 로컬에서 정상 응답하지만 Cloudflare에서 시간 초과가 발생합니다. CGV 조회 실패와 간헐적인 이마트24 지연도 남아 있습니다. 디트릭스 카탈로그와 입력 검증은 이용할 수 있으나 실시간 상영·좌석 조회의 운영 복구는 아직 확인되지 않았습니다. 비용 한도는 올리지 않았습니다.
