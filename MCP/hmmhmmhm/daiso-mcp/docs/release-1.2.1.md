# 1.2.1 릴리스 노트

## 올리브영 중계 운영

중계 브라우저의 탭 재사용, 사용량·시간에 따른 세션 정리, RSS 감시와 요청 watchdog을 추가했습니다. 별도 guard가 브라우저를 소유하며 부모 프로세스의 강제 종료에도 회수를 담당합니다. 소유한 프로세스의 종료를 확인하지 못하면 새 브라우저를 만들지 않습니다.

모든 중계 조회에 재시작 후에도 유지되는 분당 30회·UTC 일일 3,000회 상한을 적용했습니다. 본문 읽기 중인 요청도 8개 슬롯 상한에 포함하며 브라우저 응답은 2MiB로 제한합니다.

Cloudflare Access 서비스 인증을 Worker 운영 바인딩에서 전달합니다. 리다이렉트를 거절해 인증 정보가 다른 서버로 전달되지 않게 했습니다. 중계용 전용 표준 macOS 계정 설치 도구와 운영 절차를 추가했습니다.

## 적용 범위

Zyte 사용 중지 정책은 유지합니다. 중계 코드의 배포만으로 Mac과 Cloudflare가 연결되지는 않습니다. 운영자는 전용 GUI 계정, Access 정책, Tunnel, DNS와 Worker secrets를 구성하고 실제 조회를 검증해야 합니다. 설치 도구의 기본 실행은 변경 없는 계획 출력입니다.
