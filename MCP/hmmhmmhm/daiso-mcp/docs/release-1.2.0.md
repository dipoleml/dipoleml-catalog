# 1.2.0 릴리스 노트

## Zyte 사용 중지

Zyte Extract 네트워크 호출과 유료 재시도 경로를 제거했습니다. 서버의 REST·MCP·운영 검사 모두 같은 정책을 따릅니다. 기존 ZYTE_API_KEY가 남아 있어도 유료 요청은 발생하지 않습니다. 비용 정책에 따른 조회 불가는 재시도 불가 진단을 반환합니다.

기존 무료 원본 요청과 롯데마트 소켓·세션 재시도는 유지합니다. 무료 경로가 차단된 서비스는 조회할 수 없을 수 있습니다. 계정의 구독·약정이나 다른 프로그램의 사용량은 별도이며 이 릴리스가 계정 계약을 변경하지는 않습니다.

## 올리브영 무료 전송

올리브영 클라이언트를 유료 전송에서 직접 HTTP 및 운영자가 구성하는 인증된 브라우저 중계로 전환했습니다. 중계 주소와 토큰은 운영 바인딩에서만 전달합니다. 잘못된 설정은 반복 재시도 대신 운영자 조치를 안내합니다.

선택적인 로컬 중계는 전용 headed Chromium을 사용하며 네 가지 고정 조회 경로만 제공합니다. 인증, 16KB 요청 제한, 필드 검증, 직렬 처리와 대기 상한을 적용합니다. 사용자 브라우저 프로필이나 로그인 정보를 가져오지 않습니다.

2026-09-15 로컬 실측에서 네 API 모두 정상 JSON을 반환했습니다. 일반 HTTP 및 headless 브라우저는 차단돼, 이 경로를 운영에 사용하려면 GUI 세션과 상시 실행 장비가 필요합니다. 중계 구현과 로컬 검증 완료는 공개 서버 복구 완료를 뜻하지 않습니다.

## 조회 재사용

세븐일레븐 상품·카탈로그·인기 검색어는 5분, 매장 검색은 30분 동안 서비스 계층에서 재사용합니다. REST와 MCP의 같은 조회를 합치고 결과 복제·실패 제거·메모리 상한을 적용했습니다. 실시간 재고는 이 새 캐시에 넣지 않습니다.

## 응답 검증

올리브영의 직접/중계 응답은 HTTP 200과 SUCCESS 본문을 확인합니다. 공용 HTTP 유틸리티는 선택적으로 기대 상태를 지정할 수 있으며 기존 요청의 기본 동작과 응답 본문 읽기 제한 시간은 유지합니다.

서비스별 검증 결과와 제약은 [Zyte 없는 운영 정책](zyte-free-access.md)을 참고하세요.
