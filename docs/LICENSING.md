## What is licensed under CC BY 4.0

documentation** under Creative Commons Attribution 4.0 International
(CC BY 4.0). Attribution should name **Dipole ML Inc.** and link to
<https://dipoleml.com>.

This license does not apply to third-party integrations. Each item remains
under its upstream license.

## Accepted upstream licenses

The catalog vendors items only when the upstream project uses one of:

- MIT
- Apache-2.0
- BSD-2-Clause
- BSD-3-Clause
- ISC
- MPL-2.0
- CC0-1.0
- Unlicense

Every item records its SPDX license and pinned commit in `dipoleml.json`.
Every item keeps its upstream `LICENSE` and `NOTICE` files.

## Excluded repositories

Repositories with no license, `NOASSERTION`, unknown terms, share-alike
licenses, or copyleft licenses are not redistributed in this catalog. They are
listed for review in
[`../Catalog/excluded-repositories.json`](../Catalog/excluded-repositories.json).

Exclusion is not a judgment about quality. It is a licensing decision that can
be revisited if the upstream project adds a compatible license or grants
permission.

ID, name, vendor, upstream repository, commit, license, and path. Each item's
