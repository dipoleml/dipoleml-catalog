# Self-Drive (自驾) Roadbook

A driver's roadbook is executable on the road. Never just "起终点 + 总里程 + 一张图
+ 一句提醒".

## Every driving day must give

1. The **complete road chain** — order of waypoints and the main roads used.
2. **≥3 checkpoints** in drive order: suggested departure · en-route fuel/food stop ·
   the decision or turnaround node · arrival / latest pull-over.
3. Separately: sightseeing dwell, parking and shuttle times — never folded into
   "pure driving".
4. Fuel/charging windows and any leg you **cannot** rely on refuelling.
5. Legal parking / transfer points; lunch & dinner areas; tonight's lodging area
   and its parking condition.
6. The day's cost line (fuel, tolls, parking, lodging, food, tickets) that ties
   back to the trip total.
7. The **weather/closure replan**: at which node you decide to stop early or add a
   night, and how that shifts later nights, the vehicle handover and the return.

## Driver execution card (show beside the route)

- reference km + pure driving time (wide range OK — never present a nav estimate
  as verified)
- hard departure / return cut-offs
- parking + in-park shuttle
- why this lodging area
- **备选预案 / 路况提醒**: when to change the plan, where to re-lodge, how cost changes

## Single-driver baseline

- Two travellers ≠ two drivers. If the driver count is unknown, plan to what a
  **single** driver can safely do; anything beyond that must be split into segments
  or carry an explicit two-driver condition + re-lodging cost.
- Long mountain roads: state segmented driving time and real rest/queue margin.
  Times are *scheduling suggestions*, not arrival promises.
- Set the day's **红眼线**: the latest point after which night driving is off.
- Return day: keep buffer for vehicle return and the long-haul leg; never stack a
  long mountain drive + sightseeing + a tight flight on one day.

## When a road closes

Do not keep the itinerary by swapping in one unverified detour. Pause, add a night,
or re-sequence — and say which later bookings/nights change as a result.
