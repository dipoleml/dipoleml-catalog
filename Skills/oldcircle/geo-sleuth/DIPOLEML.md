# Geo Sleuth

**DipoleML integration** for Oldcircle. Type: `skill`. Version: `0.0.0`.

An agent skill that finds where a photo was taken — OpenStreetMap geometry, elevation skylines, satellite imagery and street view — and shows its work. Works with DipoleML, Codex, Cursor, Gemini CLI, OpenCode and GitHub Copilot.
