# Example Calibration Round

This is the shape of a calibration file produced during capture mode (see SKILL.md, Phase 3 →
"Delivery: editable file"). The agent writes a file like this to a gitignored scratch path; the user
edits each `YOUR EDIT` block inline and saves; the agent reads it back and diffs edits into rules.

Conventions: plain text, no blockquotes, no leading indentation, one block per item, an explicit
edit sentinel the user overwrites.

HOW TO USE: Under each item, replace the `‹edit here›` line with how you'd actually write it.
If the attempt already nails it, just write `good`. Terse edits are fine. Save the file when done.
