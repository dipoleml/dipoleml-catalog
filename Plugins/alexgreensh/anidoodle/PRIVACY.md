# Privacy

anidoodle runs entirely on your own machine, inside the coding agent you install it in.

- **It collects nothing.** No telemetry, no analytics, no accounts, no API keys, and no data sent to the author or anyone else.
- **What it touches.** It reads the files and images you point it at, such as a reference picture for a style, and writes the pictures, films, sound and code it makes into your project folder.
- **What it downloads.** The first render in a project installs the engine's open-source dependencies from the npm registry and a Chromium build through Playwright. Those downloads follow the npm and Playwright terms.
- **Your agent is separate.** The model and harness you run anidoodle in (Claude, Codex, Grok or another) handle your prompts under their own privacy terms.

Questions: open an issue at https://github.com/alexgreensh/anidoodle/issues.
