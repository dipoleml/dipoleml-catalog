# Fit to Sentient's six public-goods beliefs

Observed from the [Sentient grants criteria](https://sentient.foundation/grants)
on 2026-08-03. These are design commitments, not slogans.

| Sentient belief | Citadel implementation and evidence | Remaining gate |
|---|---|---|
| Open | MIT code; public schemas, adapters, methods, privacy-safe cells, reports, negative results, and offline verifiers | Keep every grant-funded artifact under an OSI-compatible license |
| Yours to keep | Local repository state and receipts work without a Citadel account or hosted endpoint; public evidence can be reconstructed offline | Release bundles must remain downloadable and fork-reproducible |
| Accessible | `/do` is the beginner entry point; local Qwen studies ran on an 8 GB GTX 1070; the public holdout rejected weak local and Claude routes rather than assuming they were useful | One workstation and one model pair do not prove broad hardware accessibility; the funded matrix must improve the retrieval/edit substrate and span hardware profiles and representative work |
| Good for humanity | The intended public benefit is more reliable, lower-cost access to coding-agent capability and honest evidence when optimization fails | Demonstrate measurable cost/access improvement on real operations before claiming impact |
| Private by default | Project state and telemetry stay local by default; sensitive paths, secrets, and raw provider output are excluded from public evidence | Adapter privacy tests and documented provider boundaries must pass for every stack |
| Empowering, not extractive | No token, mandatory cloud, telemetry resale, proprietary receipt service, or runtime lock-in; users retain code and evidence | Preserve those terms in funded releases and governance |

Citadel's strongest fit is infrastructural: it helps open agent builders test
whether cheaper execution remains useful after verification, without requiring
them to surrender their stack, project state, or evidence to Citadel.
