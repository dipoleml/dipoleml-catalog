# Brand Docs

**DipoleML integration** for Ferdinandobons. Type: `plugin`. Version: `0.10.1`.

BrandDocs is a set of agent skills that learn your existing Word, PowerPoint and Excel templates and generate new on-brand documents from them. Unlike generic AI document generators, it preserves brand, structure, styles and formulas by construction. Built for DipoleML, Codex and compatible AI agents.
